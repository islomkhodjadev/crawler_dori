# Dori — как работает система (текущее состояние)

## Архитектура

**Стек:** Python 3.12, FastAPI, SQLite, Playwright/Chromium, openpyxl  
**Сервер:** `predictor.03dorixona.uz`, сервис `dori` (systemd)  
**Ветка:** `experiment/chrome-agent`

---

## Сбор цен

### ArzonApteka

1. Сервер открывает Chromium через Playwright (`admin.search('arzon', product)`)
2. Переходит на `https://arzonapteka.uz/search?q=<search_term>`
3. Парсит карточки товаров (название, цена, URL)
4. Сопоставляет с товаром из базы (`matching.py`)

`search_term()` для Arzon: обрезает название до первой дозировки/формы, сохраняет бренд. Пример: «NOW ВИТАМИН Д3 2000МЕ капс» → «NOW ВИТАМИН Д».

### Oson (через Chrome Extension Agent)

Oson блокирует серверные IP-адреса. Используется Chrome-расширение:

1. Расширение установлено на компьютере пользователя, держит WebSocket к серверу (`/api/agent/ws`)
2. При запросе сбора сервер проверяет `agent_bus.connected()`
3. Если агент подключён — сервер отправляет задание через WebSocket: `{type: "fetch", url: "https://osonapteka.uz/search?q=..."}`
4. Расширение выполняет `fetch()` в браузере пользователя, возвращает HTML
5. Сервер парсит HTML: сначала JSON-LD (`parse_oson_jsonld`), затем видимые карточки (`parse_oson_cards`)
6. Если результатов нет — запрашивает у GPT-4o-mini до 3 альтернативных поисковых запросов (`ai.search_term_variants`) и повторяет шаги 3–5 для каждого

`search_term()` для Oson: убирает латинские слова в начале (напр. «NOW»), восстанавливает суффикс буква+цифра (напр. «Д3»). Пример: «NOW ВИТАМИН Д3 2000МЕ» → «ВИТАМИН Д3».

## Сопоставление товаров (`matching.py`)

Для каждого найденного предложения:

1. Нормализация: NFKC, lowercase, Cyrillic/Latin, единицы измерения
2. Очистка скобок из названия (два прохода — для вложенных скобок вида «(NOW Vitamin D-3 (USA))»)
3. Извлечение атрибутов: дозировка, форма, объём, количество в упаковке, бренд
4. Сравнение атрибутов с эталоном:
   - Жёсткие конфликты (другая дозировка, другая форма) → `rejected`
   - Полное совпадение всех атрибутов → `accepted`
   - Частичное совпадение → `review` (требует ручного подтверждения)
5. AI-предложения всегда идут в `review`

## Расчёт рыночной цены

- Для каждого сайта: медиана принятых (`accepted`) цен
- Рыночная цена = медиана из медиан двух сайтов
- Если один сайт недоступен → `single_source`
- Оптимальная цена рассчитывается через GPT по запросу (кнопка «✨ Рассчитать»)

## Chrome Extension

Файлы: `chrome-extension/`

| Файл | Роль |
|---|---|
| `manifest.json` | Manifest V3, права: `storage`, `webRequest` |
| `background.js` | WebSocket к серверу, очередь задач `fetch`, пинг-понг каждые 20 сек |
| `popup.html/js` | Статус подключения, поле пароля; URL сервера вписан по умолчанию |

Расширение скачивается с сайта: вкладка «2 Подключение» → «Скачать расширение (.zip)».  
Zip собирается на лету из папки `chrome-extension/` при каждом запросе.

## Ключевые файлы

| Файл | Роль |
|---|---|
| `dori/app.py` | FastAPI-приложение, все HTTP/WS эндпоинты, AgentBus |
| `dori/service.py` | Оркестрация сбора, маршрутизация Oson → агент или Chromium |
| `dori/adapters.py` | `agent_search_oson`, `_fetch_oson_page`, парсеры Arzon/Oson |
| `dori/matching.py` | Нормализация, `search_term`, `attributes`, скоринг |
| `dori/ai.py` | `search_term_variants`, `get_advice` (оптимальная цена) |
| `dori/static/index.html` | SPA: 5 вкладок + вкладка «? Справка» |
| `dori/static/app.js` | Клиентская логика, polling прогресса, review UI |
| `dori/static/i18n.js` | Переводы RU / UZ / EN |
| `data/dori.sqlite3` | База: товары, предложения, результаты сборов |
