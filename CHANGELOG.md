# Changelog

## [master] — ноябрь 2026

### Chrome Extension Agent
- Новое расширение Chrome (`chrome-extension/`) — работает как прокси между сервером и Oson
- Расширение держит WebSocket к серверу, получает задания на загрузку страниц и возвращает HTML
- Страницы Oson загружаются через браузер пользователя (его IP не заблокирован)
- Zip скачивается прямо с сайта: вкладка «2 Подключение» → «Скачать расширение»
- Адрес сервера вписан в popup по умолчанию — пользователь вводит только пароль
- `AgentBus` в `app.py` управляет WebSocket-соединением и очередью задач

### Исправления Oson
- `service.crawl()` теперь маршрутизирует Oson через агента даже в admin-пути (раньше игнорировал `agent_bus`)
- `search_term()` для Oson: убирает латинские слова в начале (напр. «NOW»), восстанавливает суффикс буква+цифра (напр. «Д3») — устраняло выдачу «Витамин А», «B12» вместо нужного товара
- `attributes()`: двупроходная очистка скобок в названиях вида «Витамин Д-3 (NOW Vitamin D-3)» — бренд-скор вырос с 0.52 до 0.80
- AI-фолбэк: если основной запрос вернул страницу без предложений — GPT-4o-mini генерирует до 3 альтернативных запросов, каждый пробуется через агента

### Excel-экспорт
- `/api/export/xlsx` — сводная таблица результатов (зелёный заголовок, автоширина)
- `/api/export/candidates/xlsx` — все найденные предложения
- Кнопки добавлены в интерфейс, переводы в `i18n.js` (RU/UZ/EN)

### Вкладка «? Справка»
- Встроенная документация прямо на сайте на трёх языках
- Разделы: установка расширения Chrome, подключение к серверу, ArzonApteka (с предупреждением о геолокации), сбор цен, FAQ
